# XML for Silex

`XML` builds, parses, traverses, and serializes strict XML documents. It
preserves document structure and rejects DTD declarations and custom entity
expansion explicitly.

```text
silex install XML
```

- [French documentation](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)
